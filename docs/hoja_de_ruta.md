# Hoja de ruta

## Entregado

- Visualizador estático y portable de nueve niveles.
- Siete capas territoriales, filtros espaciales y por atributos.
- Tabla completa, ordenable y desplazable, ficha y exportación.
- Fuentes originales, script de actualización y documentación.

## Mejoras futuras (no incluidas)

- Validación topológica completa con PostGIS y reporte de discrepancias espaciales.
- Filtros multiselección y consultas cruzadas entre niveles.
- Búsqueda por radio y agrupamiento de puntos a escalas pequeñas.
- Versión completamente offline con biblioteca Leaflet y mapas base locales.
- Pruebas automatizadas en navegador y publicación mediante GitHub Pages.
